# سوال:
برنامه‌ای بنویسید که عدد n را از ورودی گرفته و فاکتوریل آن را محاسبه کرده و نمایش دهد.

منظور از فاکتوریل یک عدد مانند n که با نماد n! نشان‌ داده می‌شود؛ ضرب اعداد 1 تا n است. به عبارت دیگر:
```text
n!=1×2×3×⋯×n
```
#### ورودی
در یک خط عدد n به شما داده می‌شود.
```py
1≤n≤10
```
#### خروجی
مقدار n فاکتوریل را در خروجی چاپ کنید.
#### مثال
#### ورودی نمونه ۱
```py
5
```
#### خروجی نمونه ۱
```py
120
```
```text
5!=1×2×3×4×5=120
```
# جواب:
#### روش ۱
```py
n = int(input())
f = 1
for i in range(1, n + 1):
    f *= i
print(f)
```
